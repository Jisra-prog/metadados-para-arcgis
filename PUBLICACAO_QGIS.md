# Checklist para publicação no repositório oficial do QGIS

Antes do envio ao repositório oficial:

- [ ] Testar a v1.2.1 no QGIS 3.44.13.
- [ ] Confirmar no ArcGIS que `Faixa de Escala` aparece como esperado.
- [ ] Definir um e-mail público de contato e preencher `qgis_metadata_arcgis/metadata.txt`.
- [ ] Concluir o manual ilustrado.
- [ ] Confirmar autorização institucional para a identificação MIDR/DOH/SNSH.
- [ ] Alterar `experimental=True` para `experimental=False` quando a versão estiver estável.
- [ ] Manter `repository`, `homepage` e `tracker` apontando para o GitHub público.
- [ ] Gerar um ZIP instalável com uma única pasta-raiz `qgis_metadata_arcgis/`.
- [ ] Enviar a versão pelo portal oficial de plugins do QGIS usando uma conta OSGeo.
